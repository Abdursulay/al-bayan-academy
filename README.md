# Al-Bayan Qur'an & Arabic Academy 🌙

Official website and digital enrollment portal for **Al-Bayan Qur'an & Arabic Academy** — an online madrasa offering structured, personalized 1-on-1 Qur'an recitation, Tajweed, Hifz, and Arabic language instruction for children and adults globally.

---

## ✨ Features

- **Royal Islamic Aesthetic:** Bespoke color palette (Islamic emerald & champagne gold), traditional arabesque accents, and sacred calligraphy.
- **Interactive Placement Tool:** 30-second assessment wizard that evaluates age, skill level, and goals to recommend tailored curriculums.
- **Virtual Classroom Preview:** Live class indicator, Surah Al-Mulk preview with color-coded Tajweed guidelines (Madd, Ghunnah, Qalqalah), and interactive audio simulator.
- **Curriculum Filter Tabs:** Clear tracks for Qur'an Recitation, Memorization (Hifz), Classical Arabic Language, and Adult Learners.
- **Tuition & Plans:** Transparent scheduling packages (Foundation, Accelerated Growth with sibling discounts, and Intensive Hifz).
- **Direct WhatsApp Concierge:** Instant application integration pre-populating student details directly into WhatsApp for rapid onboarding.
- **Interactive FAQ Accordion:** Answers to common parent and learner questions.
- **Fully Responsive:** Optimized for desktops, tablets, and mobile devices with a slide-out navigation drawer.

## 🚀 Local Development

No package installation or build tools required. Simply clone the repository and open `index.html` in any web browser:

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
# Open index.html in your default browser:
start index.html
```

---

## 🌐 Deployment to GitHub Pages

1. Push this repository to GitHub on the `main` branch.
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your site will be published at `https://<your-username>.github.io/<repo-name>/`.
